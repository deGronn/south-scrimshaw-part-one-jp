## 翻訳範囲

- 本編の台詞すべて（全4章）と、リンクから開く補足の解説

設定画面（OPTIONS）の「言語 / Language」で、日本語と英語をいつでも切り替えられます。初回は日本語で起動します。

### ダウンロードしたファイルの検証（任意）

[`.sha256`](../../releases/latest/download/SouthScrimshawPartOneJP.zip.sha256) ファイルを併せて配布しています。PowerShell で確認できます。

```powershell
Get-FileHash .\SouthScrimshawPartOneJP.zip -Algorithm SHA256
```

表示された値が `.sha256` の中身と一致すれば、ファイルは破損・改竄されていません。

## 導入方法

zip を解凍し、次のどれか1つを実行してください。どれを選んでも結果は同じです。

### 方法1: `インストール.bat`（おすすめ）

ダブルクリックするだけです。Steam の登録情報からゲームの場所を自動で探すので、
表示された場所で合っていれば、**何も入力せずに Enter を押してください**。

見つからなかった場合や、別の場所に入れている場合は、フォルダを入力します。
エクスプローラからフォルダをウィンドウへ**ドラッグしても入力できます**。

### 方法2: PowerShell

```powershell
PowerShell -ExecutionPolicy Bypass -File .\INSTALL_JP_PATCH.ps1 -GameRoot "ゲームフォルダのパス"
```

### 方法3: 手動でコピー（Mac・Linux もこちら）

zip の中の `game` フォルダを、ゲームフォルダの `game` フォルダに上書きコピーしてください。

### ゲームフォルダの場所

`SouthScrimshaw.exe` があるフォルダです。Steam 版の既定では以下にあります。

```
C:\Program Files (x86)\Steam\steamapps\common\South Scrimshaw Part One
```

Steam ライブラリでゲームを右クリック →「管理」→「ローカルファイルを閲覧」でも開けます。

方法1・2では、導入の前に配布ファイルが壊れていないか（SHA-256 の照合）と、ゲームが起動していないかを確認します。
前の版の上から導入して問題ありません。上書き前のファイルは自動でバックアップされます。

## 自動アップデート

ゲームの起動時に新しい版があるかを確認し、あれば**タイトル画面**でお知らせします（Windows のみ）。

- **更新する** を選ぶとゲームが終了し、更新が終わると自動でゲームが再起動します。
  **今回はしない** は次回の起動時にもう一度確認、**この版は飛ばす** はその版をスキップします。
- お知らせはタイトル画面でだけ表示します。物語の途中で割り込むことはありません。
- 更新はゲームを終了してから行います。プレイ中にファイルを書き換えることはありません。
- ダウンロードしたファイルは、作者の署名と SHA-256 を確認してから適用します。確認できない場合は何も変更しません。
- 更新前のファイルは `_SouthScrimshawPartOneJP_Backups` へ自動でバックアップされます。途中で失敗した場合は自動で元に戻します。
- 起動時の確認で通信する先は GitHub だけです。ゲームや利用者の情報は送信しません。オフラインのときは何もせずに起動します。
- Mac・Linux では、新しい版があることと配布ページの案内だけを表示します。

自動アップデートを使わない場合は、ゲームフォルダの `game` フォルダから
`zz_jp_updater.rpy` と `zz_jp_updater.rpyc` を削除してください（通信も行わなくなります。翻訳はそのまま使えます）。

## 翻訳以外にゲームへ加えている変更

### 原作の不具合の修正

補足（フランシス・クリックのインタビュー、微生物）を開いたり戻ったりすると、
設定画面の**音楽の音量が書き換えられ、最大になってしまう**不具合を直しています（原作の英語版にもある不具合です）。
声の間だけ音楽が小さくなる演出はそのままです。

修正は `game/zz_jp_bugfix.rpy` に入っています。このファイル（と `.rpyc`）を削除すると、原作どおりの動きに戻ります。

### 録音の日本語字幕

補足「フランシス・クリック」では、クリックとワトソンの対話の録音（記録映画『The DNA Story』1973 年より）が流れますが、
原作には字幕がありません。英語では聞いて分かる内容が日本語では伝わらないため、**日本語を選んでいるときだけ**、
録音に合わせて翻訳者が作成した字幕を表示します。英語を選んでいるときは、原作どおり字幕は出ません。

字幕は `game/zz_jp_subtitles.rpy` で表示しています。このファイル（と `.rpyc`）を削除すると、字幕だけが表示されなくなります。

### 画像の文字

画像の中の英語は、原作の絵を含まない重ね合わせ用の画像（自作の文字と塗りつぶし）で日本語にしています。
英語を選んでいるときは、原作の画像がそのまま表示されます。

### 台詞の改行

台詞は、日本語として読みやすい位置（文節の切れ目、なるべく句読点の後）で改行し、行の長さをそろえています。
4行になる台詞だけ、画面の下にはみ出さないよう、1行分上にずらして表示します。

## アンインストール（元に戻す）

### 方法1: `UNINSTALL_JP_PATCH.ps1`

zip に同梱の `UNINSTALL_JP_PATCH.ps1` を実行すると、パッチで追加したファイルだけを削除します。

```powershell
PowerShell -ExecutionPolicy Bypass -File .\UNINSTALL_JP_PATCH.ps1 -GameRoot "ゲームフォルダのパス"
```

前の版に戻したい場合は、`_SouthScrimshawPartOneJP_Backups\（日時）\` にある `RESTORE_JP_PATCH.ps1` を実行してください。

### 方法2: 手動で削除

ゲームフォルダの `game` フォルダから、以下を削除してください。

- `zz_japanese.rpy` / `zz_japanese.rpyc`
- `zz_jp_bugfix.rpy` / `zz_jp_bugfix.rpyc`
- `zz_jp_subtitles.rpy` / `zz_jp_subtitles.rpyc`
- `zz_jp_updater.rpy` / `zz_jp_updater.rpyc`
- `jp_patch_installed.json`
- `jp_updater` フォルダ
- `jp` フォルダ
- `fonts\jp` フォルダ
- `tl\japanese` フォルダ

パッチは原作のファイルを上書きしないので、上記を削除すれば元どおりになります。
削除後も言語の設定が「日本語」のまま残りますが、翻訳が無いため英語で表示されます（動作に問題はありません）。
バックアップ（ゲームフォルダの `_SouthScrimshawPartOneJP_Backups`）は自動では消えないので、不要なら削除してください。
